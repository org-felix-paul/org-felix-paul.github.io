# org-felix-paul.github.io

Organization site for [org-felix-paul](https://github.com/org-felix-paul).

It serves the root of `github.felix-paul.de` and, because a custom domain on an
organization site is inherited by all project sites of the same account, it also
puts every other Pages repo under that domain — e.g. `github.felix-paul.de/readmybook`.

Plain static HTML, no build step.
